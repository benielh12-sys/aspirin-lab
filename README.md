# Aspirin: Molecular Action

An interactive 3D model of aspirin (acetylsalicylic acid, C₉H₈O₄) showing how its acetyl group transfers to Ser530 of cyclooxygenase. Built for a Grade 12 chemistry presentation.

- **Explore**: rotate and zoom the molecule, click any atom or bond for details.
- **Functional groups**: aromatic ring, carboxylic acid, ester and acetyl group.
- **Acetyl transfer**: a five-stage animation of aspirin acetylating Ser530 (a simplified educational representation).
- **Hand controls** (optional): webcam hand tracking with MediaPipe. Video is processed locally in the browser and is not uploaded.

## Run it

- Online: open the GitHub Pages site for this repository.
- Offline on a Mac: double-click `Start Aspirin Lab.command`. It serves this folder on your computer and opens it in Chrome.

Molecular geometry is the PubChem CID 2244 3D conformer. Bundled libraries and their licenses are listed in [vendor/README.md](vendor/README.md).
